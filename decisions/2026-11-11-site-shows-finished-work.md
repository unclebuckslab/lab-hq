# The site shows finished work only

Made Nov 11, 2026, in the planning Project; corrected Nov 14. Changes part of `2026-11-10-site-and-newsletters.md`.

| Decision | Reason |
| --- | --- |
| The site is a library of every finished project: live ones, plus retired (archived) ones that stay up | Finished work is the lab's record, including work that's no longer running |
| Work in progress never appears on the site: nothing with status `in-the-lab` or `paused` | The site presents finished work, not the lab's to-do list |
| No "In the lab" framing, status badges or stage trackers on the site. Retired projects get one plain line, "No longer updated," and sit after live work | Readers should know when something isn't kept current; nothing more is needed |
| Those status labels stay internal, in the registry and Lab Desk | They're for running the lab, not for presenting it |
| Work in progress is covered in the lab dispatch | Keeps learning in public, in the place built for it |
| A project goes on the site by setting its registry status to `live`, and stays when it moves to `archived` | One switch, no site edits; the AI Money Report flips at launch |
