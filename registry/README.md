# Registry

The one place the lab's project list, stages, hours and data sources live. The site, the projects board and the weekly briefing read these files; nothing else keeps its own copy.

Run `python registry/validate.py` after any edit. It fails on a missing field, an unknown value or a broken reference. Add `--report` to list what needs the founder and where projects overlap on sources.

## projects.yaml

| Field | Meaning |
| --- | --- |
| `id` | Short, permanent, lowercase with hyphens |
| `name` | Public name |
| `working_name` | `true` until the name is final |
| `endorsement` | The line under the name on the site |
| `type` | `recurring-report`, `dashboard`, `reference-database`, `visual`, `brand`, `product` or `writing` |
| `stage` | `idea`, `explore`, `define`, `build`, `review`, `launch`, `operate`, `improve` or `archived` |
| `status` | Public label: `in-the-lab`, `live`, `paused`, `archived` or `parked` (parked projects never show publicly) |
| `show_on_site` | Whether the site lists it |
| `priority` | 1 is highest |
| `repo` | `owner/name`, or `null` |
| `public_url` | Where the live thing is, or `null` |
| `summary` | One sentence for the project card; follows the writing rules |
| `playbook` | Path to its playbook, or `null` |
| `agents` | Squad roles that work on it |
| `next_milestone` | A milestone `id`, or `null` |
| `notes` | Anything the next session needs to know |

## milestones.yaml

| Field | Meaning |
| --- | --- |
| `id` | Short code: `S` setup, `M` lab, `B` brand, `D` data layer, `P` project, `L` launch, `K` kit |
| `name` | What it delivers |
| `after` | Milestone ids that must be done first |
| `est_hours` | Estimated focus hours |
| `actual_hours` | Logged focus hours; `null` until work starts |
| `status` | `not-started`, `in-progress` or `done` |
| `done_means` | The test for calling it done |

## sources.yaml

Every data source the lab pulls or has approved. A project pulls only from a source listed here and publishes it only where `publish` is true ([decision](../decisions/2026-11-21-lab-data-layer.md)). A project's own source notes (DorkGraphs' `sources/source-library.md`, the AI Money Report's `config/sources.yaml`) may add detail but never contradict this file; where they differ, this file wins and the project file gets fixed.

| Field | Meaning |
| --- | --- |
| `id` | Short, permanent, lowercase with hyphens |
| `name` | The publisher and dataset |
| `tier` | Set by the founder (tiers below), or `null` when none is set |
| `tier_approved` | Date the founder approved the tier, or `null` while it's a proposal |
| `license` | `cleared`, `cleared-with-conditions`, `confirm` (terms silent or unclear; written confirmation needed) or `not-cleared` |
| `license_checked` | Date of the last terms check; `null` only for `confirm` sources not yet checked. Re-check yearly |
| `conditions` | Rules that travel with the data (privacy, wording, attribution) |
| `credit` | The credit line on anything published |
| `covers` | What's in it, in one or two sentences |
| `known_breaks` | Changes in how it's measured, and quirks that have bitten us |
| `access` | API, downloads, hand-kept table |
| `status` | `active` (a pipeline pulls it), `listed` (approved, not pulled yet), `blocked` (can't be used until a license question is settled) or `retired` |
| `publish` | Whether figures from it may appear in public work. `false` for every `confirm` or `not-cleared` source |
| `pipelines` | Each pull: `repo`, `path`, `schedule`. Empty unless `active` |
| `used_by` | Project ids that use or plan to use it |
| `notes` | Anything the next session needs to know |

**Tiers** (taken from DorkGraphs, where they started):

- **A. Official.** Government statistical agencies, official international bodies, and legally required public filings and records.
- **B. Research.** Peer-reviewed datasets, nonpartisan survey organizations with published methods, and private data with a published methodology.
- **R. Reported.** Figures from outside official statistics, usable only from the organization's own required filing, the measuring organization's own announcement, or two independent reputable outlets.
- **C. Not usable for published figures.** Advocacy organizations, undisclosed methods, and numbers generated by the lab's own agents.

A high tier doesn't grant the right to republish; that's `license` and `publish`.

`discovery_tools` lists sites used to find data (FRED, Our World in Data). They are never the credited source.

Adding a source: add a record with a proposed tier and `tier_approved: null`, set `publish: false` until the license is checked, and open a PR. Retiring one: set `status: retired` and clear `pipelines` once nothing reads it.
